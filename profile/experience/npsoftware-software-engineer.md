Freelance software engineer providing complete bespoke solutions.

I worked on a single contract for a bespoke green-screen application used by American Express at Wimbledon, called "Pose with the Pros". Visitors to the event could have their photograph taken next to an American Express sponsored star, then optionally have it printed. The application ran on a single computer and delivered hundreds of photographs.

The application was written in VB.NET, with a custom C++ DirectShow transform filter that performed chroma keying in real time.
